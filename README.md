## 🌟 Introduction | හැඳින්වීම | அறிமுகம்

**සිංහල:**  
මෙය **PHP** සහ **MySQL** භාවිතයෙන් සාදන ලද සම්පූර්ණ **Student Management System** එකකි. මෙම පද්ධතිය තුළ සිසුන් එකතු කිරීම, සංස්කරණය කිරීම, මැකීම, සෙවීම, වාර්තා බැලීම, භාෂා 3කින් (සිංහල, English, தமிழ்) වැඩ කිරීම, සහ PDF ලෙස අපනයනය කිරීමේ හැකියාව ඇත. මෙය **Admin** සහ **Viewer** ලෙස භූමිකා 2ක් සහිතව ක්‍රියාත්මක වේ.

**English:**  
This is a complete **Student Management System** built with **PHP** and **MySQL**. It includes features for adding, editing, deleting, searching students, viewing statistics, language switching (Sinhala, English, Tamil), and exporting data to PDF. It supports **Admin** and **Viewer** roles with role-based access control.

**தமிழ்:**  
இது **PHP** மற்றும் **MySQL** பயன்படுத்தி உருவாக்கப்பட்ட ஒரு முழுமையான **மாணவர் மேலாண்மை அமைப்பு** ஆகும். மாணவர்களைச் சேர்த்தல், திருத்துதல், நீக்குதல், தேடுதல், புள்ளிவிவரங்களைப் பார்த்தல், 3 மொழிகளில் (சிங்களம், ஆங்கிலம், தமிழ்) செயல்படுதல், மற்றும் PDF ஆக ஏற்றுமதி செய்தல் போன்ற அம்சங்களை இது கொண்டுள்ளது. **நிர்வாகி** மற்றும் **பார்வையாளர்** என்ற இரு பாத்திரங்களை ஆதரிக்கிறது.

## ✨ Features | විශේෂාංග | அம்சங்கள்

- 🔐 **Login System** – Admin / Viewer roles with hashed passwords
- 👥 **User Registration** – New users can register as viewers
- 🔑 **Forgot Password** – Reset password using security question
- 📝 **CRUD Operations** – Create, Read, Update, Delete students
- 🔍 **Search** – Search students by name or class
- 📊 **Dashboard** – Statistics: Total students, Average age, Class-wise bar chart
- 🌐 **Language Switcher** – Switch between Sinhala, English, Tamil (fully translated UI)
- 🖼️ **Profile Picture** – Upload and display profile images
- 📄 **Export to PDF** – Generate PDF of student list (using Dompdf)
- 🛡️ **Role-Based Access** – Admin (full control) vs Viewer (view-only)
- 📱 **Responsive Design** – Works on desktop, tablet, and mobile
